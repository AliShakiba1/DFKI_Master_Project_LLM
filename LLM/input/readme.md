## 📁 Included Files

This example package contains three distinct files to help you compare the raw data against different transcription approaches:

### 1. Raw GoPro Video

* **Description:** The original, unprocessed point-of-view video footage captured during the recorded session. This serves as the visual baseline for object detection and hand tracking.

### 2. Initial Transcription (Joanna Sorysz)

* **Description:** The baseline text transcription. This file demonstrates the specific timing, phrasing, or alignment issues that are documented in `naration.md`. It serves as a reference for what the pipeline needs to correct or filter out.

### 3. Optimized Transcription (Ali)

* **Description:** The refined and optimized transcription. This version represents the ideal text format for this pipeline, containing the correct timestamps and clean text required for seamless merging with the 3-second temporal chunks and downstream LLM reasoning.
